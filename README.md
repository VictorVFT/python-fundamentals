# python-fundamentals

Este repositório contém códigos de exercícios que desenvolvi no início dos meus estudos de Python, seu foco é lógica de programação e fundamentos básicos.

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Status](https://img.shields.io/badge/status-learning-green)

## 📚 Conteúdos praticados
- Entrada e saída de dados
- Condicionais
- Loops
- Operações matemáticas
- Pequenos programas interativos


## Objetivo 🎯:
  Desenvolver afinidade prática com a lógica de programação e experimentar sua aplicação em projetos simples.

## ▶️ Como executar

1. Clone o repositório:
```bash
git clone https://github.com/Victor_VFT/python-fundamentals.git
```
2. Acesse a pasta do projeto no terminal ou qualquer editor de código compatível.
```bash
cd python-fundamentals
   ```
3. Execute um dos arquivos Python.
```bash
python calculadora_terminal.py
   ```
